# RepoPilot MVP plan

| Weeks | Deliverable |
|---|---|
| 1-2 | GitHub App integration, repo indexing, FastAPI skeleton, Docker Compose |
| 3-4 | Issue ingestion, hybrid retrieval, context packing |
| 5-6 | Sandbox runner, reproduction, Ollama patch generation |
| 7-8 | Approval UI (React), test reports, draft PRs |
| 9-12 | Security hardening, benchmark suite, docs, pilot |

Pipeline (LangGraph): ingest issue -> retrieve files -> explain -> reproduce -> propose patch -> test in sandbox -> human approval -> draft PR.
